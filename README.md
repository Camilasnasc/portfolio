## 📖 Sobre o Projeto

Portfolio pessoal desenvolvido para apresentar meus projetos e habilidades como desenvolvedora em formação. O site possui design moderno com tema roxo, animações suaves e totalmente responsivo.

## ✨ Funcionalidades

- 🎨 Design moderno e minimalista
- 📱 Totalmente responsivo (mobile-first)
- ⚡ Navegação suave entre seções
- 🎭 Animações e efeitos visuais
- 🌟 Cards interativos de projetos
- 💌 Links para redes sociais

## 🚀 Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização personalizada
- **JavaScript** - Interatividade e scroll suave
- **Tailwind CSS** - Framework CSS utilitário (via CDN)
- **Font Awesome** - Ícones (via CDN)

## 📂 Estrutura do Projeto

```
portfolio/
│
├── index.html          # Página principal
├── css/
│   └── style.css      # Estilos personalizados
├── js/
│   └── main.js        # Scripts JavaScript
└── README.md          # Documentação
```

## 🎯 Seções

1. **Início** - Apresentação e call-to-action
2. **Sobre** - Informações pessoais e tecnologias
3. **Projetos** - Portfólio de projetos desenvolvidos
4. **Contato** - Redes sociais e formas de contato

## 💻 Como Executar

1. Clone o repositório:
```bash
git clone https://github.com/Camilasnasc/portfolio.git
```

2. Abra o arquivo `index.html` no navegador
