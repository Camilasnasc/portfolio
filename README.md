## 📖 Sobre o Projeto

Portfólio pessoal de página única, criado para reunir meus projetos e habilidades como desenvolvedora em formação. Design **dark** moderno com destaque em **verde esmeralda**, animações suaves de scroll e layout totalmente responsivo (mobile-first).

## ✨ Destaques

| | |
|---|---|
| 🎨 | Design dark moderno com acento esmeralda |
| 📱 | Responsivo (mobile-first) |
| ⚡ | Navegação com scroll suave entre seções |
| 🎭 | Animações de *fade-in* via `IntersectionObserver` |
| 🌟 | Cards de projetos interativos |
| 💌 | Links diretos para e-mail, GitHub e LinkedIn |

## 🚀 Tecnologias

- **HTML5** — estrutura semântica
- **CSS3** — estilização personalizada e gradientes
- **JavaScript** — interatividade, scroll suave e animações
- **Tailwind CSS** — framework utilitário (via CDN)
- **Font Awesome** — ícones (via CDN)
